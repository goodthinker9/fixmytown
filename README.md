# FixMyTown

A community problem reporting platform. Residents report broken water points, power outages, potholes and garbage buildup with a photo and a map pin. Everyone can see reports, upvote issues they share, and track status. Admins update statuses and see stats.

> Status: in development (Phase 0 - project setup)

## The problem

In many towns there is no easy way to report local infrastructure problems. Reports get lost, and nobody can see which areas are most affected or whether issues get fixed.

## The solution

- Report an issue in under a minute (photo, location, description)
- Public map and list with filters
- Status tracking: reported, in progress, resolved
- Upvotes so the most-affected issues rise to the top
- Admin dashboard with charts

## Tech stack

- Frontend: React (Vite), React Router, Leaflet, Recharts
- Backend: Node.js, Express, JWT authentication
- Database: PostgreSQL on Supabase
- Storage: Supabase Storage (report images)
- Deploy: Render (backend), Vercel (frontend)
